# EFCquiz
Treinamento, presença e avaliação de eficácia (PWA). Faz parte do sistema EFClaudian. Versão 2.3.0.

Site: https://eliasgrigori.github.io/EFCquiz/  (atenção: **EFCquiz** com E, F e C maiúsculos e "quiz" minúsculo; o GitHub Pages diferencia maiúscula de minúscula)

- Primeiro acesso: pelo item **EFCquiz** do menu do EFClaudian. Depois, o mesmo usuário e senha do EFClaudian.
- Quem só participa de um treinamento entra pelo QR ou link que o instrutor mostra (sem conta).
- Demonstração: abra o site com `?demo=1` no fim do endereço.
- Visual e temas iguais aos do EFClaudian (o tema é o do EFClaudian neste aparelho).
- O endereço antigo (`/efclaudian/efcquiz/`) só redireciona para este.

## Arquivos (todos juntos na raiz do repositório)
| Arquivo | O que é |
|---|---|
| `index.html` | o app inteiro (arquivo único) |
| `sw.js` | guarda o app no aparelho para abrir sem internet |
| `manifest.webmanifest` | nome, cores e ícones para instalar |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` | ícone em aquarela (Q com ✓) |
| `abertura.jpg` | arte da tela de abertura (app instalado) |
| `ios/abertura-*.jpg` | a mesma abertura nos 12 tamanhos de iPhone |
| `README.md` | este arquivo |

O `icon.svg` da v2.2.0 não é mais usado e pode ser apagado do repositório.
